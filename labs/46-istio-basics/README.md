## Done when

- [ ] Install Istio with `istioctl` or Helm; explain istiod (control plane) and the Envoy sidecars (data plane)
- [ ] Sidecar injection per namespace; inspect a sidecar's config with `istioctl proxy-config`
- [ ] An ingress gateway for the demo app, configured with **Gateway API**
- [ ] Map Istio's own APIs (VirtualService, DestinationRule, Gateway) to Gateway API equivalents, and know when you still need the Istio ones
- [ ] Debug a misconfiguration with `istioctl analyze`
